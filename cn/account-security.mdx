# 账号安全性问题

本章节用于回答关于账号安全、封号风险与 Spam 风险的常见疑问。

## 1. API 安全性

除 ViralLibrary（不涉及账号关键操作的推文库）外，我们会优先使用官方 API

## 2. 关于 Spam 问题

- 内容建议：在 Context 中录入您的 Persona，会使您的回复质量进一步提升。
- 风险建议：遵循我们的最佳实践，避免 24 小时一直开启 ReplyBot，则能有效避免您被判定为 Spam。

## 3. 滥用与合规声明

1. 我们严格禁止账号滥用行为，禁止多个用户利用我们的平台同时操纵同一个推特/X 账号；并且不提倡用户在一天内批量发送垃圾信息。我们的平台并未提供任何批量发送 Post 的功能。若您的账号因这类违反推特/X 平台政策的行为被封禁，本平台不承担任何责任。

2. 我们严格遵守推特/X 平台规定，禁止任何违法行为、敏感词汇或平台禁止内容从本平台进行发布。一经发现，将进行封号处理，后果自负。
