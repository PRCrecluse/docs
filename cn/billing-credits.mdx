# 计费与 Credits

## 1. Credits 是什么？

Credits 可以理解为「大模型调用额度」。所有在 Chatbox 中对话、生成内容、调用模型的行为，都会根据实际使用的 tokens 从 Credits 中扣除。

- 输入 tokens：你发送给模型的内容（包括最近对话上下文）
- 输出 tokens：模型返回给你的内容
- 每一次对话的总消耗 = 输入 tokens + 输出 tokens

## 2. 会员与每月可用 Credits

你可以在定价页或 Billing 页面中购买或切换会员。不同会员方案每月包含的 Credits 如下：

| 方案 | 价格 | 每月 Credits |
| --- | --- | --- |
| Hobby（按月） | $40 / 月 | 500 |
| Professional（按月） | $200 / 月 | 2000 |
| Hobby（年付） | $400 / 年 | 500（每月发放） |
| Professional（年付） | $2000 / 年 | 2000（每月发放） |

方案能力概览（与产品页一致）：

- Hobby：最多创建 5 个 personas、基础运营建议、日历与提醒、Auto-reply workflows、优质内容发现与改写、5GB 存储（单文件上限 50MB）
- Professional：不限 personas、专业运营建议、日历与提醒、Auto-reply workflows、优质内容发现与改写、50GB 存储（单文件上限 200MB）

## 3. Chatbox 中不同模型的 Credits 扣费标准

我们会根据你选择的模型，对「本轮对话产生的总 tokens 数」按不同单价折算为 Credits：

- 以每 1,000 tokens 为计费单位（不足 1,000 按比例计算）。
- 总 tokens = 输入 tokens + 输出 tokens。
- 不同模型有不同的每 1,000 tokens 消耗标准。

| 模型 | Credits / 1,000 tokens | 说明 |
| --- | --- | --- |
| PersonaAI（Gemini 3.0 Pro） | 0.9 | 高级推理与创作模型，适合内容生产、深度分析等场景。 |
| Nanobanana / GPT5.2 / Gemini3.0 Pro / Minimax M2 / Kimi0905 | 0.45 | 高性价比通用模型组合，适合日常问答、创意辅助、运营建议。 |

## 4. Auto-reply 扣费标准

Auto-reply 的扣费由「帖子拉取」与「生成回复」两部分组成：

- 帖子拉取：0.1 credit / 次
- 普通回复：0.5 credit / 条
- 带 meme 的回复：在普通回复基础上，每条额外 +2 credits

## 5. 实际扣费示例

示例 A：在 Chatbox 中使用 PersonaAI（Gemini 3.0 Pro）进行一次典型对话：

- 输入约 500 tokens
- 输出约 800 tokens
- 总 tokens ≈ 1,300 tokens

本轮大约扣除：

**1,300 ÷ 1,000 × 0.9 ≈ 1.17 Credits**

示例 B：Auto-reply 生成 1 条普通回复（并拉取 1 次帖子）：

**0.1 + 0.5 = 0.6 credits**

示例 C：Auto-reply 生成 1 条带 meme 的回复（并拉取 1 次帖子）：

**0.1 + 0.5 + 2 = 2.6 credits**

## 6. 查看用量与历史

你可以在应用内随时查看 Credits 余额和详细的使用记录：

- 登录后，进入右上角头像菜单中的 Settings。
- 切换到「Usage History」标签页，查看扣费记录与 Credits 变化。
