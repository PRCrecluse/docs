# SalesBot 销售机器人使用手册

SalesBot 用于围绕客户名单进行分轮私信触达与跟进，帮助您系统化完成销售对话。

## 1. 基本流程

1. 选择客户名单并创建 Task。
2. 第一轮发送后，进入触达阶段（触达客户）。
3. 对方回复后，系统会将该用户标记为可进入第二轮。
4. 第二轮发送完成后，进入跟进阶段（已跟进）。

## 2. 触达 / 跟进定义

- **第一轮**称为「触达客户」。
- 仅当对方回复了我们的第一轮消息，才会标记该用户为：
  - **已触达**
  - **需跟进**
- **第二轮**才称为「跟进」：
  - 当我们完成第二轮回复后，该用户才会被标记为 **已跟进**。

## 3. 页面指标说明

- **当前任务总回复数**：当前任务名单规模（用于发起触达的目标用户数）。
- **当前任务触达数**：当前任务中，已成功发送 DM 的去重用户数。
- **跟进数**：当前任务中，进入并完成跟进阶段的用户数。
- **总触达数 / 总跟进数**：当前账号下所有任务的累计统计。

## 4. 发送限制

为保护账号安全并遵循平台限制，SalesBot 与 AutoDM 共用以下限制：

- 每分钟最多发送 1 条 DM；
- 24 小时最多发送 200 条 DM。

命中限制后任务会自动顺延；若因滥用导致账号受限或封禁，平台不承担责任。
