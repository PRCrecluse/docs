# Viral Library 使用手册

Viral Library 是您的灵感来源与内容库，帮助您快速发现高质量推文并进行创作。

## 1. 推荐内容

在 **Recommended** 部分，您不仅可以看到推荐的**优质账号**，还能看到**热门推文**。

> **注意**：由于数据库限制，推荐账号的关注数及发帖数数据可能存在一定滞后性，但这不影响 Viral Library 中推文内容的极佳质量。

## 2. 保存为模板 (Save as Template)

在每一条帖子下方点击 **Save as template** 按钮，即可将该帖子保存为您的创作模板。

- 保存后，您可以在 **Queue** -> **Template** 页面找到该模板。
- 您可以对模板进行二次编辑，使其符合您的 Persona 风格。

## 3. 日历 (Calendar)

**Calendar** 页面允许您对推文进行定时发布管理，并制定属于您的内容日历。

- 拖拽或点击日期即可安排发帖计划。
- 直观查看已发布和待发布的推文。

## 4. Playbook 使用最佳实践

- 根据现在的推特算法，如果同一个账号一天发布过多的 posts 可能会造成部分流量衰减；建议一天只发布 2-3 条最佳。
- 与同领域、垂直的账号保持尽量活跃的互动；强烈建议您每天关注同领域的 5-20 个账号。
