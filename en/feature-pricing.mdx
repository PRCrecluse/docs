# Feature Pricing

This page summarizes Credits pricing for core actions so you can estimate usage cost quickly.

## Pricing Overview

| Feature | Price |
| --- | --- |
| Send Direct Message | 0.4 credit / request |
| Fetch Timeline | 0.1 credit / request |
| AI Reply | 0.1 credit / request |
| Extract users from tweets | 0.1 credit / request |
| Journal refresh | 0.1 credit / request |
| Find users | 0.01 credit / request |
| Search Engine | 80 credits / request |
| SalesBot | User-defined capped pricing (charged under your configured cap) |

## Notes

- These rates reflect current pricing and will be updated on this page if changed.
