# Quickstart

If you're new to VolumnAI, this is the shortest path to get productive.

## Get Started

- Enable at least one model in Settings → Models.
- Use VolumnAI for complex tasks; use cost-effective models for daily tasks.
- After you start chatting, check Credits usage in Settings → Usage History.

## Best Practices

- Keep prompts concise—long context increases input tokens.
- Keep outputs focused. For long outputs, ask for an outline first, then expand section by section.
- Choose models based on task complexity.

## FAQ

- Costs higher than expected: check total tokens (input + output), especially long context or verbose outputs.
- Model unavailable: confirm API keys are configured on the server, or switch to an enabled model.
- Slow responses: shorten outputs, reduce context, or switch models.
