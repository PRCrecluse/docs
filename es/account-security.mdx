# Seguridad de la Cuenta

Esta sección responde preguntas comunes sobre la seguridad de la cuenta, riesgos de bloqueo y riesgos de spam.

## 1. Seguridad de API

A excepción de ViralLibrary (una base de datos de tweets que no implica operaciones críticas de cuenta), utilizamos **API oficiales** para todas las operaciones. No existe **ningún riesgo** de bloqueo debido al uso de la API.

## 2. Sobre el Spam

- **Consejo de Contenido**: Agregar su **Persona** al **Contexto** mejorará aún más la calidad de sus respuestas.
- **Consejo de Riesgo**: Siga nuestras mejores prácticas y **evite ejecutar el ReplyBot las 24 horas del día**. Esto previene eficazmente que sea marcado como spam.
