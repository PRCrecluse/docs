# Precios por Función

Esta página resume los precios en Credits de las acciones principales para estimar el coste de uso rápidamente.

## Resumen de precios

| Función | Precio |
| --- | --- |
| Enviar Direct Message | 0.4 credit / solicitud |
| Obtener Timeline | 0.1 credit / solicitud |
| Respuesta con IA | 0.1 credit / solicitud |
| Extraer usuarios desde tweets | 0.1 credit / solicitud |
| Actualización de Journal | 0.1 credit / solicitud |
| Buscar usuarios | 0.01 credit / solicitud |
| Search Engine | 80 credits / solicitud |
| SalesBot | Precio con tope definido por el usuario (se cobra bajo tu límite configurado) |

## Notas

- Estas tarifas son las actuales y se actualizarán en esta misma página si cambian.
- Puedes ver cada descuento y el saldo restante en Settings > Usage History.
