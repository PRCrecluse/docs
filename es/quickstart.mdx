# Inicio rápido

Si es tu primera vez con Volumn.ai, estos pasos te ayudan a empezar rápido.

## Primeros pasos

- Activa al menos un modelo en Settings → Models.
- Usa Volumn.ai para tareas complejas; usa modelos más económicos para tareas diarias.
- Después de iniciar un chat, revisa el consumo de Credits en Settings → Usage History.

## Buenas prácticas

- Mantén los prompts concisos: un contexto largo aumenta los tokens de entrada.
- Mantén las respuestas enfocadas. Para respuestas largas, pide primero un esquema y luego expande por secciones.
- Elige el modelo según la complejidad de la tarea.

## Preguntas frecuentes

- Coste más alto de lo esperado: revisa los tokens totales (entrada + salida), especialmente si el contexto es largo o la salida es muy extensa.
- Modelo no disponible: confirma que las API keys estén configuradas en el servidor o cambia a un modelo activado.
- Respuestas lentas: reduce la longitud de salida, acorta el contexto o cambia de modelo.
