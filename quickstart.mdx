# 快速开始

如果你刚开始使用 Persona AI，这里是最短路径的上手步骤。

## 上手步骤

- 在 Settings → Models 启用至少一个模型。
- 复杂任务优先选择 PersonaAI；日常任务选择性价比更高的模型。
- 开始对话后在 Settings → Usage History 查看 Credits 扣费与余额。

## 最佳实践

- 保持提示词精炼，过长上下文会增加输入 tokens。
- 输出尽量简短聚焦；需要更长输出时，先让模型给提纲再逐段展开。
- 复杂任务用 PersonaAI，轻量问答用组合模型。

## 常见问题

- 扣费高于预期：请检查总 tokens（输入 + 输出）是否过高，尤其是上下文过长或输出过多。
- 模型不可用：请确认服务端已配置 API Key，或切换到已启用的模型。
- 响应较慢：尝试缩短输出、减少上下文，或更换模型。
