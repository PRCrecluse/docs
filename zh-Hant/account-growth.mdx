# 帳號增長指南

### 帳號增長最佳實踐

推特平台演算法已在 GitHub 對外公開。根據已公開的資訊，我們知道：

評論在演算法中的權重已大幅提升。

根據我們的測試，一個成長良好的帳號至少應符合以下條件：

（1）每日發布 2–3 則推文

（2）維持較高的評論數量

（3）及時回覆其他用戶對自己推文的回覆。

因此建議您：

將回覆工具（extension）與推特爆文庫工具搭配使用，才能達到最佳效果。

- 首先，確保自己在 Context 部分已經取得完整的 context，從而獲得盡量精準的推送與回覆。
- 其次，建議 ReplyBot 的時間間隔保持在 2 min，減少被判定為 Spam 的可能。

### Posts 發布建議

雖然 ViralPosts 有非常多豐富的創作模板，但在如今資訊繁雜的時代，大家其實更願意看到一個更加真實、廣告量更少的你。

- 強烈建議你在推特上發布一些自己的生活日常：可以是生活小事和照片，也可以是每天更新自己情況的小影片。
