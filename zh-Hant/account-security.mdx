# 帳號安全性問題

本章節用於回答關於帳號安全、封號風險與 Spam 風險的常見疑問。

## 1. API 安全性

除 ViralLibrary（不涉及帳號關鍵操作的推文庫）外，我們會優先使用官方 API；在部分情境下也可能使用第三方整合/資料服務來補充能力。我們會盡量降低帳號風險，但無法保證 0 封號風險。

## 2. 關於 Spam 問題

- **內容建議**：在 Context 中錄入您的 Persona，會使您的回覆品質進一步提升。
- **風險建議**：遵循我們的最佳實踐，避免 24 小時一直開啟 ReplyBot，則能有效避免您被判定為 Spam。
