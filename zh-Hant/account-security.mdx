# 帳號安全性問題

本章節用於回答關於帳號安全、封號風險與 Spam 風險的常見疑問。

## 1. API 安全性

除 ViralLibrary（不涉及帳號關鍵操作的推文庫）外，我們會優先使用官方 API；

## 2. 關於 Spam 問題

- **內容建議**：在 Context 中錄入您的 Persona，會使您的回覆品質進一步提升。
- **風險建議**：遵循我們的最佳實踐，避免 24 小時一直開啟 ReplyBot，則能有效避免您被判定為 Spam。

## 3. 濫用與合規聲明

1. 我們嚴格禁止帳號濫用行為，禁止多個使用者利用我們的平台同時操縱同一個推特/X 帳號；並且不提倡使用者在一天內大量發送垃圾訊息。我們的平台並未提供任何批量發送 Post 的功能。若您的帳號因這類違反推特/X 平台政策的行為而被封禁，本平台不承擔任何責任。

2. 我們嚴格遵守推特/X 平台規定，禁止任何違法行為、敏感詞彙或平台禁止內容從本平台進行發佈。一經發現，將進行封號處理，後果自負。
