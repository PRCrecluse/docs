# 快速開始

如果你剛開始使用 Volumn.ai，這裡是最短路徑的上手步驟。

## 上手步驟

- 在 Settings → Models 啟用至少一個模型。
- 複雜任務優先選擇 Volumn.ai；日常任務選擇性價比更高的模型。
- 開始對話後在 Settings → Usage History 查看 Credits 扣費與餘額。

## 最佳實踐

- 保持提示詞精煉，過長上下文會增加輸入 tokens。
- 輸出盡量簡短聚焦；需要更長輸出時，先讓模型給提綱再逐段展開。
- 複雜任務用 Volumn.ai，輕量問答用組合模型。

## 常見問題

- 扣費高於預期：請檢查總 tokens（輸入 + 輸出）是否過高，尤其是上下文過長或輸出過多。
- 模型不可用：請確認服務端已配置 API Key，或切換到已啟用的模型。
- 回應較慢：嘗試縮短輸出、減少上下文，或更換模型。
