# Viral Library 使用手冊

Viral Library 是您的靈感來源與內容庫，幫助您快速發現高品質推文並進行創作。

## 1. 推薦內容

在 **Recommended** 部分，您不僅可以看到推薦的**優質帳號**，還能看到**熱門推文**。

> **注意**：由於資料庫限制，推薦帳號的關注數及發帖數數據可能存在一定滯後性，但這不影響 Viral Library 中推文內容的極佳品質。

## 2. 保存為模板 (Save as Template)

在每一條帖子下方點擊 **Save as template** 按鈕，即可將該帖子保存為您的創作模板。

- 保存後，您可以在 **Queue** -> **Template** 頁面找到該模板。
- 您可以對模板進行二次編輯，使其符合您的 Persona 風格。

## 3. 日曆 (Calendar)

**Calendar** 頁面允許您對推文進行定時發布管理，並制定屬於您的內容日曆。

- 拖曳或點擊日期即可安排發帖計劃。
- 直觀查看已發布和待發布的推文。

## 4. 常見問題

### 如果我推到的'趨勢'或者模板不準確怎麼辦？

一般是由您的 **Context** 這裡填寫的資訊不準確引起的：

**（1）我們建議您先在 Context 填寫好合適的資訊，設置好合適的 Bio 這樣才會推到準確的內容。**

**（2）推特帳號的設置，尤其 Bio 對於您的帳號增長至關重要。請務必撰寫準確的定位。**

例如：`19y/o, builder, designer, building volumn.ai`（行業資訊、項目資訊、身份年齡等）。

## 5. Playbook 使用最佳實踐

- 根據現在的推特演算法，如果同一個帳號一天發布過多的 posts 可能會造成部分流量衰減；建議一天只發布 2-3 則最佳。
- 與同領域、垂直的帳號保持盡量活躍的互動；強烈建議您每天追蹤同領域的 5-20 個帳號。
